 # Template V5

This template repository is based from [Godot 4.4.1 stable](https://godotengine.org/download/archive/4.4.1-stable/).

Template V4 and previous are all based from Godot 3.5.1 stable.

Only use this repository upon instruction by your top supervisor (Sir Kenoms).

## Instructions

Create your own folder on the **Production** folder. Artists will only deal with **Production** and nowhere else on this repository.

Developers will use the **New Game** folder. Delete folders/files in that folder that you don't need, such as the **New-Game/World** folder and the **Sample Novel**, **Sameple Game** and **Sample Custom** inside the **New-Game/Game** folder. Do this before doing anything else.
